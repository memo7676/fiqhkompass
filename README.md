# Fiqh-Kompass

Eine Lernseite zum Fiqh-Unterricht, basierend auf den Folien „Fiqh Unterricht 1–16“ (Google-Drive-Ordner „Fiqh“).

- **Nachschlagen**: alle 11 Themengebiete (Quellen, Madhabs, Rechtskategorien, Ṭahāra, Wuḍūʾ, Ġusl & Moschee, Tayammum, Ḥayḍ/Nifās, Gebet, Fasten) mit Volltextsuche.
- **Quiz**: Themenquiz (ein oder mehrere Gebiete) oder gemischter Modus, 5/10/15 Fragen, Punkte mit Zeit- und Serienbonus, 50:50-Joker, Bestwerte und Auswertung mit Links zum Nachlesen.

Einfach `index.html` im Browser öffnen, ohne Build-Schritt. Inhalte und Fragen stehen in `data.js`.
